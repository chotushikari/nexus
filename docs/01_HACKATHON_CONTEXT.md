# HACKATHON CONTEXT

## Event

All Things Agentic Hackathon

## Selected Track

# Fortified Enterprise Fleet

The project must be designed around enterprise-scale agent discovery, orchestration, persistence, identity, governance, security and observability.

---

# Mandatory Technology Requirements

The project must use:

* Gemini 3.5 or newer
* at least one Google agent framework
* at least one Google Cloud service

Selected framework:

**Google ADK**

Selected model:

**Gemini 3.5 Flash**, subject to current availability.

Selected Google Cloud infrastructure:

* Cloud Run
* Firestore

Additional services may include:

* Pub/Sub
* Cloud Logging
* Cloud Trace
* Cloud Storage
* Model Armor
* Gemini Enterprise Agent Platform capabilities where practical

---

# Track 3 Focus

The Fortified Enterprise Fleet track focuses on:

* corporate agent discovery
* multi-agent orchestration at scale
* long-term state persistence
* runtime observability
* security posture enforcement

The product should demonstrate how an organization can discover agents, understand what they are doing, control their access, preserve state, observe execution and safely scale autonomous work.

---

# Recommended Capability Mapping

Agent Registry:
agent discovery, ownership, versioning, capabilities and lifecycle.

Agent Runtime:
long-running asynchronous execution.

Memory:
persistent cross-session context and mission state.

Agent Identity:
zero-trust agent identities and permissions.

Agent Gateway:
routing and policy enforcement.

Model Armor:
guardrails against prompt injection, tool poisoning and PII-related risks.

Agent Observability:
audit logs, events and execution traces.

---

# Judging Strategy

The project should make each capability visible and demonstrable.

Do not rely on documentation alone.

Every major claim should have:

* implementation evidence
* UI evidence
* demo evidence
* test evidence where appropriate

---

# Important Product Positioning

Do not pitch the project as:

"an AI office."

Pitch it as:

> "A visual operating environment for governed autonomous enterprises."

The office is the interface.

The agent infrastructure is the product foundation.

---

# Demo Scenario

The user operates a fictional enterprise.

The user starts:

> "Evaluate ACME Technologies and onboard them if they satisfy enterprise policies."

The agents autonomously:

1. research the company
2. assess compliance
3. assess financial risk
4. prepare procurement recommendation
5. encounter a governed restricted action
6. request human approval
7. continue after approval
8. complete the mission

The entire process is observable through NEXUS.
