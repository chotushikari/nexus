# Rules

Before incorporating source code:

1. Identify repository.
2. Identify license.
3. Determine compatibility.
4. Record exact files/components used.
5. Preserve required notices.
6. Document modifications.
7. Do not copy incompatible code.

---

# Preferred Strategy

Prefer:

* standard open-source libraries
* small reusable components
* architectural inspiration
* independent implementation

Avoid creating a dependency chain of multiple complete agent-control platforms.
