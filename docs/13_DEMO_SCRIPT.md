# NEXUS — 4-MINUTE DEMO

## Opening

Show complete enterprise office.

Voiceover:

> "This is NEXUS — a visual operating environment for an autonomous enterprise."

---

# 0:00–0:20 — The Enterprise

Show:

* Executive Office
* Research
* Finance
* Compliance
* Procurement
* Security
* Data

Explain:

> "Every room represents a real part of the agent infrastructure. Every employee you see is a real autonomous agent."

---

# 0:20–0:40 — Start Mission

User enters:

> Evaluate ACME Technologies and onboard them if they satisfy enterprise policies.

Orchestrator activates.

---

# 0:40–1:20 — Multi-Agent Collaboration

Research agent activates.

Show tool call.

Research sends information to Compliance.

Compliance evaluates policies.

Finance evaluates financial risk.

Procurement prepares recommendation.

---

# 1:20–1:50 — Persistence

Show mission state.

Demonstrate or narrate:

> "The workflow is persistent rather than tied to the browser."

If practical, show reopening/reconnecting to the mission.

---

# 1:50–2:30 — Security

Inject malicious instruction through synthetic vendor document.

Security system detects it.

Show:

SECURITY ALERT
PROMPT INJECTION DETECTED
ACTION BLOCKED

---

# 2:30–3:00 — Governance

Finance attempts restricted action.

Policy engine:

DENY or REQUIRE_APPROVAL.

Show:

> Human approval required.

Operator approves.

Agent resumes.

---

# 3:00–3:30 — Observability

Open Agent Inspector.

Show:

* identity
* permissions
* tools
* current mission
* events
* policy decisions

Open mission timeline.

---

# 3:30–3:50 — Google Technology

Briefly show:

* Gemini
* Google ADK
* Cloud Run
* Firestore
* security/observability services actually used

Do not spend excessive time on technology logos.

---

# 3:50–4:00 — Closing

> "NEXUS isn't another chatbot and the office isn't a simulation. It's a visual operating environment for autonomous agents — where humans can see what the enterprise is doing, control what it is allowed to do, and trust the work it performs."

End on the complete office.
